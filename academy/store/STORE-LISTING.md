# Chrome Web Store listing

## Name

Academy of Mercenary Arts — Command Hall

## Short description

A private medieval command hall for Academy training, resources, events, quests, focus, notes, and after-action reviews.

## Detailed description

ENTER THE ACADEMY.

The Academy Command Hall transforms Chrome’s New Tab page into a handcrafted medieval operations center built for one purpose: Developing Fighters. Building Warlords.

COMMAND THE WORK

- Set one daily Commander’s Intent.
- Manage Academy quests across the Command Hall and Field Ledger.
- Track weekly balance across Body, Craft, Mind, Character, and Fellowship.
- Protect attention with 15, 25, 45, or 60-minute Iron Ward cycles.

KEEP THE ACADEMY RHYTHM

- See recurring Wednesday training and Sunday park musters.
- Add local events manually.
- Import upcoming events from a user-selected `.ics` calendar export.
- Open Google Calendar without granting the extension account access.

UNITE THE ARCHIVES

- Open verified Academy Drive, F100, Core/Admin, Fighter Coach, ORK, and official Amtgard resources.
- Add, edit, or remove Resource Hall roads.
- Right-click a webpage to save it as an Academy resource.
- Optionally discover Academy and social links already present in Chrome bookmarks.

LEARN FROM THE FIELD

- Capture persistent field notes in the Field Ledger.
- Write structured after-action reviews: objective, success, friction, lesson, and next action.
- Export or restore the complete Chronicle with a local JSON backup.

PRIVATE BY DESIGN

No account. No analytics. No ads. No trackers. No remote code. No host permissions. No scripts that read websites. Bookmark discovery is optional and user-initiated. Calendar import reads only the file the user selects.

## Category

Productivity

## Single purpose

Provide a private Academy of Mercenary Arts New Tab productivity dashboard and synchronized side panel.

## Permission justifications

- Storage: save user-created Academy resources, tasks, events, AARs, notes, doctrine marks, settings, directive, and focus state locally.
- Side panel: display synchronized quests, field notes, AAR entry, and focus controls beside websites.
- Context menus: let the user explicitly save the current page as an Academy resource.
- Bookmarks (optional): scan bookmark titles and addresses locally only after the user invokes Academy bookmark discovery.

## Remote code

No. All executable code is packaged inside the extension.
