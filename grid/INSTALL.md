# Install GRID in Chrome

1. If Grimoire or another New Tab extension is active, disable it at `chrome://extensions`. Chrome allows only one extension to replace New Tab at a time.
2. Extract `GRID-Extension-v1.0.0.zip` to a permanent folder, such as `Documents/GRID Dashboard`.
3. Enter `chrome://extensions` in Chrome’s address bar.
4. Enable **Developer mode**.
5. Select **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.
7. On the boot screen, choose an operator alias and signal spectrum, then initialize the nexus.

If the GRID icon is hidden, open Chrome’s Extensions menu (the puzzle-piece icon) and pin **GRID // Cyberdeck Dashboard**. Clicking it opens the Ghost Deck.

## Optional neon browser theme

Extract `GRID-Neon-Theme-v1.0.0.zip`, return to `chrome://extensions`, choose **Load unpacked**, and select the extracted theme folder. This colors Chrome’s real frame and tabs to match GRID. It is cosmetic and requests no permissions.

To uninstall, return to `chrome://extensions` and select **Remove**. Export a backup from GRID // CONFIG first if you want to preserve your nodes, operations, note, and preferences.
