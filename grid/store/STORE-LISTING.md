# Chrome Web Store listing

## Name

GRID // Cyberdeck Dashboard

## Short description

Turn every new tab into a private neon cyberdeck for nodes, operations, focus, notes, and system signals.

## Detailed description

OPEN A TAB. ENTER THE GRID.

GRID replaces Chrome’s ordinary New Tab page with a handcrafted cyberpunk operations nexus designed to protect attention and make everyday browsing feel extraordinary.

ROUTE THE NETWORK

- Create and edit node shortcuts for trusted destinations.
- Right-click any webpage to register it as a GRID Node.
- Route direct addresses or search with Google, DuckDuckGo, Bing, or Brave.
- Optionally reveal recent bookmarks and frequently visited routes.

RUN THE MISSION

- Set one daily Primary Directive.
- Track operations across the full dashboard and Ghost Deck side panel.
- Execute a 15, 25, 45, or 60-minute Focus Protocol.
- Capture passing data in a persistent scratch buffer.
- Receive one original Signal Fragment each day.

CONFIGURE THE DECK

- Choose Cyan, Magenta, Acid, or Amber signal spectra.
- Use full, system-controlled, or reduced motion.
- Select a search provider, clock style, text size, date display, and optional completion signal.
- Export or restore local state with a JSON backup.

PRIVATE BY DESIGN

GRID contains no account, advertising, analytics, trackers, remote code, host permissions, or scripts that read websites. Bookmark and frequent-site permissions are optional, requested only when you activate those features, and revocable at any time.

Your browser should feel like an instrument—not a waiting room.

## Category

Productivity

## Single purpose

Provide a customizable cyberpunk New Tab productivity dashboard and synchronized side panel.

## Permission justifications

- Storage: save user-created nodes, operations, notes, settings, daily directive, and focus timer state.
- Side panel: display the synchronized operations, note, and focus companion beside websites.
- Context menus: let the user explicitly add the current page as a node.
- Bookmarks (optional): display recent bookmarks only after the user enables the Bookmark Archive.
- Top sites (optional): display Chrome’s frequent-site index only after the user enables the Route Cache.

## Remote code

No. All executable code is packaged inside the extension.
