# Privacy Policy — GRID // Cyberdeck Dashboard

Effective date: August 20, 2026

GRID does not collect, transmit, sell, share, or monetize personal information. It contains no advertising, analytics, tracking technology, account system, remote executable code, content scripts, or host permissions.

## Data stored locally

GRID stores the following information in Chrome’s extension storage on the user’s device:

- Preferences and appearance choices
- User-created node names and web addresses
- Operation text and completion state
- Daily Primary Directive text
- Scratch-buffer text
- Focus-timer state
- Onboarding completion state

GRID does not transmit this information to the developer or any third party.

## Optional browser information

If the user explicitly enables the Bookmark Archive, GRID reads recent bookmark titles and web addresses to display them on the New Tab page.

If the user explicitly enables the Route Cache, GRID reads Chrome’s frequently visited-site list to display it on the New Tab page.

These optional browser records are rendered locally and are not copied into GRID’s stored state or transmitted elsewhere. Either permission can be removed at any time in GRID // CONFIG.

## Search and external sites

When the user submits a phrase through the GRID command line, the extension navigates to the selected search provider. That provider’s privacy policy applies after navigation. When the user opens a node, bookmark, or frequent site, that destination’s privacy policy applies.

## Backups

The user may explicitly export extension data as a local JSON file and later import it. GRID does not upload backups.

## Data deletion

Users can reset all locally stored extension data in GRID // CONFIG. Removing the extension through Chrome also removes its local extension storage, subject to Chrome’s platform behavior.

## Changes

If this policy changes, the effective date and extension documentation will be updated. No future version will begin collecting or transmitting personal information without clear disclosure and the permissions required by Chrome.
