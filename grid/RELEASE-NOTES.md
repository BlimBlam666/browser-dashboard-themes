# GRID // Cyberdeck Dashboard 1.0.0

Initial complete release.

## Interface

- Replaces Chrome’s New Tab page with a responsive cyberdeck operations nexus.
- Adds a terminal-style command line for search queries and direct endpoints.
- Includes a first-run boot sequence, full configuration console, scanlines, grid depth, data-rain accents, and four neon spectra.

## Operations

- Node Matrix with eight defaults, editing, deletion, and right-click registration.
- Ops Queue synchronized across New Tab and the Ghost Deck side panel.
- Daily Primary Directive that resets with each local day.
- Shared Focus Protocol with four durations and an optional three-tone signal.
- Persistent 6,000-character scratch buffer.
- Forty original daily Signal Fragments.
- Optional Bookmark Archive and frequent Route Cache.

## Control and privacy

- System-controlled, full, or reduced motion; four text sizes; four search providers; two clock formats; optional date.
- Local JSON export, validated import, and factory reset.
- Separate optional neon Chrome theme for the real frame and tabs.
- No trackers, analytics, ads, accounts, remote code, host permissions, or site-reading scripts.
- Bookmark and top-site access remain optional and revocable.
- Manifest V3, restrictive Content Security Policy, URL-scheme validation, bounded imported data, and no external runtime dependencies.
