# The Grimoire Dashboard 1.0.0

Initial complete release.

## The threshold

- Replaces Chrome’s New Tab page with a responsive two-page spellbook.
- Adds a Scrying Mirror for web searches and direct addresses.
- Includes a matching first-run binding ceremony and full settings chamber.

## The working pages

- Portal Atlas with eight defaults, editing, deletion, and right-click inscription.
- Quest Ledger synchronized across New Tab and the Familiar’s Panel.
- Daily Oath that renews with each local day.
- Shared focus ritual with four durations and an optional three-tone chime.
- Persistent 6,000-character scratchpad.
- Forty original daily oracle reflections.

## Personalization

- Ember, Moon, Verdant, and Amethyst bindings.
- Full, system-directed, or reduced atmospheric motion.
- Four search-provider options, two clock formats, four text sizes, and optional date.
- Separate optional Ember Chrome theme for the real browser frame and tabs.

## Privacy and durability

- No trackers, analytics, advertisements, accounts, remote code, host permissions, or site-reading scripts.
- Bookmark and top-site access remain optional.
- Local JSON export, import validation, and complete reset.
- Manifest V3, restrictive Content Security Policy, URL-scheme validation, capped imported data, and no external runtime dependencies.
