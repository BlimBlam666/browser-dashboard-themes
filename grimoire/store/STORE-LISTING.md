# Chrome Web Store listing

## Name

The Grimoire Dashboard

## Short description

Transform every new tab into a private magical dashboard of portals, quests, focus rituals, notes, and daily wisdom.

## Detailed description

Open a new tab. Open a threshold.

The Grimoire Dashboard replaces Chrome’s ordinary New Tab page with a handcrafted magical command center built to protect attention and make everyday browsing feel extraordinary.

INSCRIBE YOUR WORLD

- Create and edit portal shortcuts to the places you use most.
- Right-click any web page to inscribe it as a portal.
- Optionally reveal recent bookmarks and frequently visited roads.

KEEP THE PRESENT TASK

- Name one daily oath.
- Track quests across the full dashboard and the Familiar’s Panel.
- Begin a 15, 25, 45, or 60-minute focus ritual.
- Capture passing thoughts in a persistent scratchpad.

BIND IT TO YOUR TASTE

- Choose Ember, Moon, Verdant, or Amethyst light.
- Use full, system-controlled, or reduced motion.
- Select a search provider, clock style, text size, and optional chime.
- Export or restore your records with a local JSON backup.

PRIVATE BY DESIGN

The Grimoire contains no account, advertisements, analytics, trackers, remote code, host permissions, or scripts that read websites. Bookmark and frequently visited-site permissions are optional and requested only when you activate those features.

The Grimoire exists for a simple purpose: your tools should return your attention to you.

## Category

Productivity

## Single purpose

Provide a customizable magical New Tab productivity dashboard and synchronized side panel.

## Permission justifications

- Storage: save user-created portals, quests, notes, settings, daily oath, and focus timer state.
- Side panel: display the user’s synchronized quest, note, and focus companion beside websites.
- Context menus: let the user explicitly add the current page as a portal.
- Bookmarks (optional): display recent bookmarks only after the user enables the Bookmark Vault.
- Top sites (optional): display Chrome’s frequently visited sites only after the user enables Well-Traveled Roads.

## Remote code

No. All executable code is packaged inside the extension.
