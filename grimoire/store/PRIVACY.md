# Privacy Policy — The Grimoire Dashboard

Effective date: August 20, 2026

The Grimoire Dashboard does not collect, transmit, sell, share, or monetize personal information. It contains no advertising, analytics, tracking technology, account system, remote executable code, content scripts, or host permissions.

## Data stored locally

The extension stores the following information in Chrome’s extension storage on the user’s device:

- Preferences and appearance choices
- User-created portal names and web addresses
- Quest text and completion state
- Daily-oath text
- Scratchpad text
- Focus-timer state
- Onboarding completion state

The extension does not transmit this information to the developer or any third party.

## Optional browser information

If the user explicitly enables the Bookmark Vault, the extension reads recent bookmark titles and web addresses to display them in the New Tab page.

If the user explicitly enables Well-Traveled Roads, the extension reads Chrome’s frequently visited-site list to display it in the New Tab page.

These optional browser records are displayed locally and are not copied into the extension’s stored data or transmitted elsewhere. Either permission can be removed at any time in the extension’s settings.

## Search and external sites

When the user submits a phrase through the Scrying Mirror, the extension navigates to the search provider selected by the user. The chosen provider’s own privacy policy applies after navigation. When the user opens a portal, bookmark, or frequently visited site, that site’s own privacy policy applies.

## Backups

The user may explicitly export their extension data as a local JSON file and later import it. The extension does not upload these backups.

## Data deletion

Users can reset all locally stored extension data in the extension’s settings. Removing the extension through Chrome also removes its local extension storage, subject to Chrome’s own platform behavior.

## Changes

If this policy changes, the effective date and extension documentation will be updated. No future version will begin collecting or transmitting personal information without a clear disclosure and the permissions required by Chrome.
