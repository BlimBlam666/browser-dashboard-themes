# Install the Grimoire in Chrome

1. Extract `Grimoire-Extension-v1.0.0.zip` to a permanent folder such as `Documents/Grimoire Dashboard`.
2. In Chrome, enter `chrome://extensions` in the address bar.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Select the extracted folder containing `manifest.json`.
6. On the welcome page, name the keeper and select an arcane accent.

If the extension icon is hidden, open Chrome’s Extensions menu (the puzzle-piece icon) and pin **The Grimoire Dashboard**. Clicking that icon opens the Familiar’s Panel.

## Optional Ember browser theme

Extract `Grimoire-Ember-Theme-v1.0.0.zip`, return to `chrome://extensions`, choose **Load unpacked**, and select the extracted theme folder. This colors Chrome’s genuine frame and tabs to match the Grimoire. It is cosmetic and requests no permissions.

To uninstall, return to `chrome://extensions` and choose **Remove**. Export a backup from Settings first if you want to preserve your portals, quests, and notes.
